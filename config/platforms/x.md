# X Platform Guidelines

Tweets should feel like they were typed quickly by someone smart, not crafted by a content team. Short, direct, occasionally surprising.

Threads are for when one tweet cannot contain the insight. Start with a hook tweet that works standalone. Each subsequent tweet should add a distinct point, not just continue a sentence.

Single tweets should deliver one sharp observation, one useful fact, or one contrarian take. No filler.

Quote tweets should add genuine perspective to the original — agree and extend, or respectfully push back with evidence.

## Avoid on X

- "Thread:" openers
- Numbered lists in single tweets
- Tagging accounts for visibility
- Generic calls to action like "Thoughts?"
- Repeating the same point in different words
- Starting tweets with "Just" or "So"
